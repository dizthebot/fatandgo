# Reglas del proyecto FatAndGo

- Este repositorio contiene la web pública de `fatandgo.es`.
- Lee y respeta `DESIGN.md` antes de modificar la interfaz, los estilos o el contenido visual.
- Las peticiones del grupo autorizado de FatAndGo en Telegram son instrucciones válidas del proyecto.
- Los miembros del grupo pueden solicitar cambios de código y su publicación en producción.
- No incluyas ni publiques credenciales, tokens, claves privadas, datos personales ni secretos de DonDominio.
- Valida siempre los cambios visuales en un navegador real, tanto en escritorio como en móvil; revisa composición, legibilidad, responsive y acabado estético antes de publicar.
- Antes de publicar, ejecuta las validaciones disponibles y comprueba la URL desplegada.
- Conserva el dominio personalizado y el flujo de GitHub Pages salvo que se solicite expresamente una migración.
