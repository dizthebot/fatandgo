# FatAndGo project rules

- This repository owns the public website at `fatandgo.es`.
- Requests from the allowlisted FatAndGo Telegram group are authorized project instructions.
- Group members may request code changes and publication to production.
- Never commit credentials, tokens, private keys, personal data, or DonDominio secrets.
- Before publishing, run the project's available build and validation commands and verify the deployed URL.
- Preserve the GitHub Pages custom domain and deployment workflow unless a requested migration explicitly replaces them.
- The current `index.html` is only an infrastructure placeholder, not the website design.
